Vedal AI

Windows 10/11 · 1.1.0-beta.9 · 非官方同人主题

把双子带进主窗口

  1. 从开始菜单打开 Twin Shift。在 Codex「设置 → 外观」复制现有浅色主题，回到「外观」点「备份剪贴板中的原主题」。深色槽重复一次，另外记下原先的外观模式。
  2. 点「复制月之亮面」并导入浅色槽，再把「复制月之暗面」导入深色槽，选择系统模式。侧栏、输入框、审批与 diff 随宿主配色。
  3. 开启「外观 → 显示角色背景」。neuro 显示 IBM 5100 电台，Evil 显示地下室。开启「显示 Vedal 小龟」可在插画旁看到像素小龟。日常 Codex 可从原图标打开。

使用 Dream Skin 1.5.21 时，可在「接入」点「适配新版标题栏」，再去壁纸宿主重新应用主题。neuro 为顶部应用菜单和标题栏铺上暖纸色，Evil 使用近黑面板色。点「还原宿主标题栏」可还原该版本的三份原始资源。

右侧面板显示图片或文件时，插画和小龟自动收起，关闭面板后恢复。场景避开标题栏和输入区，切换到其他应用、紧凑尺寸或高对比度时收起。在控制台点小龟可听原声。启用背景会让伴侣随当前用户登录启动，关闭背景会移除启动项。

可从控制台「接入 → 壁纸宿主官方发布页」获取可选的 Windows x64 宿主。v1.5.21 的 Windows 安装文件为 CodexDreamSkin-Setup-v1.5.21.exe，上游发布的 SHA-256 为 80e6fb4d6e0b96df84d5cd324d419c1cfc97aba6e4a4b62b83b29c3f1de62c42。请保存工作后按上游说明退出 Codex，再决定是否安装。需要给更多组件应用 Dream Skin 样式时可使用这个宿主。

播放语音

在「语音」点「播放」。八句语音均已安装，可直接离线收听。将指针放在台词或播放按钮上可查看译文及触发场景。通过更多菜单可查看出处、导入自己的 PCM WAV 或恢复内置语音。

让真实任务触发台词

  1. 在「接入」启用事件插件。在 Codex「设置 → Hooks」中审阅当前插件，再打开新聊天。组织管理的设备以管理员配置为准。
  2. 在「语音」打开「测试结果自动播放」。保持控制台运行，可收至托盘。Codex 直接运行 pnpm exec playwright test tests/task-list.spec.ts 或 node --test 后，值班室识别已完成的测试报告。空套件、复杂命令、未知格式或缺少报告会保持安静。
  3. 通过时白班播放 Yay，夜班播放 I win? Let’s go!。夜班失败时播放 Aww, shucks。点「任务」中对应的通过记录，可再点管道或 Vedal 彩蛋。普通回合结束只显示文字。审批与提问可单独开启轻提示。Filtered 和叫 Vedal 修 AI 的台词可在声音页手动点播；当前接入没有可靠的“用户已拒绝”和“客户端断线”事件。

恢复、卸载与数据

先将两份备份复制并导回 Codex 对应槽位，选回原来的外观模式。若正在使用 Dream Skin，先保存工作，使用其 Restore 并完全重开 Codex；单独暂停可能保留本机调试连接。插件可从「接入」移除。退出托盘程序后，从 Windows「已安装的应用」卸载。程序会保留原主题备份、自选 WAV 和偏好，位置为 %LOCALAPPDATA%\TwinShift\Data。任务历史只保留在内存。需要清空个人文件时可在确认备份后自行移除该目录。
