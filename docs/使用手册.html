Windows 10/11 · 1.1.0-beta.1 · 非官方同人主题

把双子带进主窗口

  1. 从开始菜单打开 Twin Shift。在 Codex「设置 → 外观」复制现有浅色主题，回到「外观」点「备份剪贴板中的原主题」。深色槽重复一次，另外记下原先的外观模式。
  2. 点「复制 Neo 浅色主题」，进 Codex 的浅色槽导入。对 Evo 深色槽重复，选择系统模式。侧栏、输入框、审批与 diff 随宿主配色。
  3. 需要插画时，打开壁纸包目录，在 Dream Skin 的 Import Theme ZIP 导入两个 ZIP，再在 Saved Themes 选班次。Neo 是 IBM 5100 电台；Evo 是近黑地下室。该宿主每套主题使用一张图，更换两张画需要手选。跟随系统控制的是原生配色。

场景包还修饰侧栏分隔线、标题栏、消息圆角、输入框悬停、工具栏与审批对话框。「窗边小龟」有独立开关，跟随符合条件的前台 Codex 大窗口；切走、缩小至窄窗口或进入高对比度模式后收起。左键听龟龟，右键打开任务反馈。系统托盘也能打开控制台。关闭窗口会收至托盘；右键托盘图标可完全退出。

可从控制台「接入 → 壁纸宿主官方发布页」获取可选的 Windows x64 宿主。v1.5.21 的 Windows 安装文件为 CodexDreamSkin-Setup-v1.5.21.exe，上游发布的 SHA-256 为 80e6fb4d6e0b96df84d5cd324d419c1cfc97aba6e4a4b62b83b29c3f1de62c42。请保存工作后按上游说明退出 Codex，再决定是否安装。仅使用主题色、原声和值班牌时可以略过壁纸宿主。

听到原声

在「原声」勾选「使用个人联机片源」并点试听。也可点台词旁的更多按钮，导入自己有权使用的本地 PCM WAV。该台词优先读取本地文件。网络片段从两处固定 HTTPS 来源取得，校验 SHA-256 并按片段响度调整；源文件改变即停止使用。关闭联机来源或正常退出会清理临时缓存。录音不随安装包分发。

让真实任务触发台词

  1. 在「接入」启用事件插件。在 Codex「设置 → Hooks」中审阅当前插件，再打开新聊天。组织管理的设备以管理员配置为准。
  2. 在「原声」打开「测试结果自动播放」。保持控制台运行，可收至托盘。Codex 直接运行 pnpm exec playwright test tests/task-list.spec.ts 或 node --test 后，值班室识别已完成的测试报告。空套件、复杂命令、未知格式或缺少报告会保持安静。
  3. 通过时白班播放 Yay，夜班播放 I win? Let’s go!。夜班失败时播放 Aww, shucks。点「任务」中对应的通过记录，可再点管道或 Vedal 彩蛋。普通回合结束只显示文字。审批与提问可单独开启轻提示。Filtered 和叫 Vedal 修 AI 的台词可在声音页手动点播；当前接入没有可靠的“用户已拒绝”和“客户端断线”事件。

恢复、卸载与数据

先将两份备份复制并导回 Codex 对应槽位，选回原来的外观模式。若正在使用 Dream Skin，先保存工作，使用其 Restore 并完全重开 Codex；单独暂停可能保留本机调试连接。插件可从「接入」移除。退出托盘程序后，从 Windows「已安装的应用」卸载。程序会保留原主题备份、自选 WAV 和偏好，位置为 %LOCALAPPDATA%\TwinShift\Data。任务历史只保留在内存。需要清空个人文件时可在确认备份后自行移除该目录。
