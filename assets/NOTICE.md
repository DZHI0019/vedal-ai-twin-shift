# 作品与署名

标题栏兼容功能沿用 Codex Dream Skin Studio contributors 的部件选择器，原项目 MIT 许可证见同目录的 DREAM-SKIN-LICENSE.txt。对应的上游版本为 v1.5.21。[上游源码](https://github.com/Fei-Away/Codex-Dream-Skin/tree/6fc42df48a6a5365011f55cc349e20c038e56d1d)

Twin Shift 是 neuro、Evil 与 Vedal 的非官方同人项目。软件代码与原创界面图标采用仓库 MIT 许可。名称、虚拟形象及商标由各自权利人拥有。[Vedal AI](https://vedal.ai/)

* `tutel.png` 为 amissmystic《Neuros of Chase》的乌龟像素图，固定版本 6ddc94f9835869e1c6c3f42213e6c74f57e9589d。`twinshift.ico` 是这张图的缩放转换。保留作者的 MIT No Attribution 许可于 TUTEL-LICENSE.md。[原图](https://github.com/amissmystic/neuros-of-chase/blob/6ddc94f9835869e1c6c3f42213e6c74f57e9589d/items/tutel.png) · [作者的作品页](https://amissmystic.itch.io/neuros-of-chase)
* `neo.jpg` 和 `evo.jpg` 是本项目以 ImageGen 生成的同人场景。白班为配有 IBM 5100 的复古电台，夜班为地下室。本项目就自有的图像贡献允许与本同人主题一起使用和修改；第三方虚拟形象、名称和商标权仍归各自权利人。neuro 的机器外观参照馆藏资料；安装包内无馆藏照片或 Pixiv 作品。[IBM 5100 馆藏资料](https://ub.fnwi.uva.nl/computermuseum/ibm5100.html)
* `attention.wav` 是本项目生成的短提示音，采用 MIT 许可。
* Windows 播放使用 NAudio 的 Core 和 WASAPI 组件，MP3 解码使用 NLayer。两个库采用 MIT 许可，许可证随程序附在 NAudio-LICENSE.txt 和 NLayer-LICENSE.txt。[NAudio](https://github.com/naudio/NAudio) · [NLayer](https://github.com/naudio/NLayer)
* 控制台使用 WPF UI 的 Fluent 控件和图标。界面库、字体及微软运行时组件的声明见 UI-LICENSES.txt。[WPF UI](https://github.com/lepoco/wpfui)
* `voices/*.mp3` 是 neuro、Evil 和 Vedal 的八段直播原声剪辑。项目维护者已确认这些录音可随 Twin Shift 源码和安装包再分发。录音权利归各自权利人，录音的其他用途依其授权条款处理。六段由 NeuroKaraoke 社区整理，声库署名 Rachinova 与 CJ。另两段由 minhtridotnet 整理。每段的出处、整理者及文件摘要列于 [语音目录](voices.json)。[NeuroKaraoke 声库](https://neurokaraoke.com/soundbites) · [minhtridotnet 片源表](https://github.com/minhtridotnet/neuro-sama-soundboard/blob/main/Sources.txt)
